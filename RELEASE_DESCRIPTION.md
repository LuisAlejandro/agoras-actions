*Agoras Actions* is a GitHub Action that wraps [Agoras](https://github.com/LuisAlejandro/agoras) for publishing, liking, sharing, and deleting posts on social networks. It supports X, Facebook, Instagram, LinkedIn, Discord, YouTube, TikTok, Threads, Telegram, and WhatsApp, plus a standalone OAuth credential-refresh flow that can write rotated tokens back to repository secrets.
